**决定：** 保留 = 行为与原版一致 · 修改 = 按确认的方案改进 · 删除 · 新增

## 全局决定

- 首次打开为**空状态 + 引导**，不再内置任何词库。
- 判分：名词**必须写冠词**；不区分大小写；ä 与 ae **不互通**；答错即判错（不单独提示“冠词错误”）。
- 不加“不会”按钮、“跳过”和间隔重复复习；不同步待测库。
- 刷新后保留测验进度；界面支持简体中文 / English / Deutsch / 日本語；深色模式暂不做（token 已预留）。
- 导航结构：手机底部 Tab Bar（测验 / 归档 / 词表 / 设置），平板与桌面使用侧边栏；同步以 Sheet 形式从归档页或设置页打开。
- 设置页：发音、数据（导出 / 导入、旧版迁移、快照历史）、关于。主色 systemIndigo `#5856D6`。
- 玻璃效果：默认自动选择渲染档位（WebGL → CSS 折射 → 仅模糊 → 不透明）；设置页可手动指定（阶段 6 接入，当前在设计系统页）。
- 动效：所有动画可打断（弹簧物理）；Sheet 半屏 / 全屏两档；通知在手机顶部、平板与桌面右下角；不加震动；Firefox 不支持页面过渡时直接切换。
- 旧数据迁移：同源自动迁移；不同源时用“旧版导出小工具”导出 JSON 后导入。部署到 HTTPS 静态托管。

> **6.1 实现说明（数据底座）。** 词库存放在 IndexedDB（`library` / `snapshots` / `snapshot-data` / `quarantine` / `state` 五个仓库），读取时逐条校验：
> 一条坏数据只隔离它自己，原始值原样移入隔离区，可在设置页导出 JSON 或清除。修改先更新界面再串行写入（只写变化的部分），

> （`src/domain/legacy`）：逐条校验，名词去掉不带冠词的答案（F-026），跳过原版自动生成、本来就不显示的“原形”题，
> 归档日期与排序原样保留；转换不了的词条原样放进隔离区（来源“旧版数据”），可以在设置页导出。原版的数据只读不删，原版照常可用。
> 新版与原版在同一网址下时，第一次打开自动迁移（词库为空时直接导入，已有内容时只提示，由用户在设置中选择合并或替换），
> 迁移记录写在应用状态中，之后不再重复。不在同一网址下时（最常见），设置页提供“导出工具”：一个独立的 HTML 文件，
> 用打开原版的浏览器打开即可把全部 `DE_QUIZ_` 键保存为 JSON；Firefox 中每个本地文件的存储相互独立，另提供控制台代码。
> 导入前先预览数量与整理说明；合并时同一课时中题面与答案都相同的词视为已存在；导入前自动保存快照，通知中可撤销；
> 原版“撤销覆盖”用的备份进入快照历史（“旧版接收同步前的备份”），仍然可以恢复。导出工具的文案只写入 textContent，
> 嵌入脚本的 JSON 转义了 `<`，无法注入标记。

> **6.7 实现说明（设备直连同步）。** 入口在归档页与“设置 → 数据 → 设备同步…”（F-070），面板是 Sheet：先选“发送 / 接收”，
